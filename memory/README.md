# Memory

Эта папка хранит только важный контекст проекта Tender Killer.

Актуальный handoff для новой сессии:

- верхний блок `README.md` в корне проекта;
- раздел `Safe supplier connector policy checkpoint` в `memory/project-context.md`.

Что сюда записываем по команде:

- ключевые продуктовые решения;
- рабочие гипотезы;
- выбранные источники данных и API;
- ограничения по законам, площадкам, нишам, марже и безопасности;
- вопросы, к которым нужно вернуться.

Что сюда не пишем:

- весь чат подряд;
- временные рассуждения;
- неподтвержденные детали без пользы для будущей разработки.
